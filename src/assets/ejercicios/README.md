# GIFs de ejercicios

Coloca aquí los GIFs animados de demostración de cada ejercicio.

## Nombres requeridos (exactos)

| Archivo | Ejercicio |
|---|---|
| `neck_stretch.gif` | Estiramiento de Cuello |
| `cat_cow.gif` | Cat-Cow (Columna) |
| `spine_extension.gif` | Extensión de Columna de Pie |
| `scapular.gif` | Retracción Escapular |
| `plank.gif` | Plancha de Núcleo |

## Especificaciones recomendadas

- Tamaño: 300×300 px o 400×300 px
- Duración: 3-5 segundos en loop
- Fondo: transparente o blanco
- Formato: GIF animado o WebP animado
- Tamaño de archivo: < 2 MB por GIF

## Fuentes gratuitas

- [Giphy](https://giphy.com) — busca "neck stretch", "cat cow yoga", "plank exercise"
- [Tenor](https://tenor.com)
- [Pixabay](https://pixabay.com/videos/) — videos que puedes convertir a GIF con ezgif.com

## Conversión de video a GIF

Si tienes un MP4, usa [ezgif.com/video-to-gif](https://ezgif.com/video-to-gif):
1. Sube el video
2. Recorta los segundos del movimiento
3. Optimiza a < 2MB
4. Descarga y renombra según la tabla de arriba
